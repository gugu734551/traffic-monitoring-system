# 模型目录

本目录用于放置**目标检测模型权重**。

仓库**不包含**训练权重文件（`.pt`），原因如下：

1. 权重体积较大，不适合直接放入 Git 仓库；
2. 训练权重属于课题成果的一部分，暂不公开。

## 使用方式

将 Ultralytics 训练导出的 `best.pt` 放入本目录：

```text
model/
└── best.pt
```

然后在程序界面中点击 **选择模型文件** 加载它。

## 没有自训练权重？

可以先用官方预训练权重跑通整条工程链路：

```python
from ultralytics import YOLO
YOLO("yolov8n.pt")   # 首次调用会自动下载到当前目录
```

注意：官方 COCO 权重的类别体系与本项目 `utils/detector.py` 中的
`CLASS_MAPPING`（小汽车 / 面包车 / 公交车 / 卡车 / 行人 / 两轮车）
并不完全一致，界面上的类别统计可能显示不全，属于预期现象。
